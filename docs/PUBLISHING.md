# Publish on GitHub / 上传 GitHub

1. Create a repository, for example **HTools_QuadDrawThrough**.
2. Extract the source ZIP. Upload or commit the **contents inside** its `HTools_QuadDrawThrough/` folder to the repository root, including `.gitignore` and `.gitattributes`. The root should directly contain `README.md`, `LICENSE`, the MEL and `qd_through/`.
3. Create a **v1.0.0** Release with the universal MEL as an asset. The source ZIP and `SHA256SUMS.txt` are optional assets. Use [CHANGELOG.md](../CHANGELOG.md) for release notes.

Suggested description: **Native Maya Quad Draw helper for occluded vertex picking and optional surface relax.**
Topics: `maya`, `quad-draw`, `retopology`, `python`, `maya-plugin`.

Upload unpacked files to the repository so GitHub displays the README and browsable source. Use release assets for downloads. Copyright attribution is **HTools contributors**; it does not require a matching GitHub account.
